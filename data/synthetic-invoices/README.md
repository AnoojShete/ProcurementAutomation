# Synthetic IT-vendor documents

21 synthetic PO/invoice/quote documents (mixed PDF and rasterized image,
including some intentionally low-quality/degraded scans and a few
near-duplicate invoices) used to test document-vendor-agent's
classification, field-extraction, vendor-dedup, and duplicate-detection
logic against more than one visual layout.

## Provenance

Generated by
`services/document-vendor-agent/scripts/synthetic_invoice_lib.py`
(`SEED = 42`, reproducible). If a cleaned reference CSV is placed at
`data/reference/it-procurement-reference.csv` (columns: `vendor_name`,
`category`, `item_name`, `unit_price`, `currency`), vendor names and
catalog items are seeded from it instead of the fallback synthetic
catalog — no such CSV was present when this corpus was generated
(`manifest.json`'s `used_reference_csv: false`), so every vendor
name/item/price here is synthetic, not real.

`manifest.json` records the ground truth (doc type, vendor, document
number, date, total, currency, whether it's a degraded scan, and which
document — if any — it's a deliberate near-duplicate of) for every file,
which is what the service's own tests check extraction against.

## Regenerating

```
cd services/document-vendor-agent
python scripts/synthetic_invoice_lib.py
```
