    Issues found in this review¶

    • Stale image: notification-agent's image was built before the SMTP-settings commit added cryptography, so its tests failed to start and the running service was out of date. Rebuilt; after any change to a service's requirements.txt, rebuild that service.
    • Escalation emails went to the level that missed its SLA, as a placeholder address, with a generic subject. Fixed (see A2).
    • SMTP encryption key (needs a decision): compose doesn't pass SMTP_ENCRYPTION_SECRET to notification-agent, so saved company SMTP passwords are encrypted with the default key in shared/security/encryption.py, which is public in the repo and not refused in production. Pass a real secret before any shared deployment, then re-save the SMTP password (old ones won't decrypt).
    • Test data from these checks is still in the stack (checklist_* and recheck_* files). Run ./scripts/reset-demo.sh before the review.
    • Tests (23 Oct): 1,276 service tests pass, plus 165 + 14 root tests; frontend typecheck and mkdocs build --strict are clean.
